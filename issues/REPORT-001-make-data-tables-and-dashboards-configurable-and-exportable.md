# REPORT-001 — Dashboards: Customize and export tables

**Product:** Reporting
**Type:** Feature
**Status:** New
**Impact:** High
**Date reported:** 2026-05-08
**Source:** [Zoom feedback index](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/zoom-feedback-index-2026.md) — 2026-05-08 Product Town Hall

## Observed
Ivo asked for useful/custom columns, consistent sorting, filters, exports, and access to agency/sub-account data. The specific existing-contact pipeline question was resolved and is excluded.

## Why it matters
Static tables force exports and manual analysis for questions the reporting UI should answer directly.

## Expected
Let users choose/reorder useful columns, sort/filter data, save views, and export tables/dashboards consistently across reporting surfaces.

## HighLevel response
Other table/reporting needs remain open.

## Official changelog verification — 2026-11-13

**Result:** Partial implementation — request remains open.

**Already available:** Dashboard general widgets support saved filters, date overrides, comparison, rename, themes and cloning.

**Scope decision:** Consistent choose/reorder/export columns, save views and table export across all Reporting surfaces is not released here.

**Official sources:** [Configure and filter your general widgets in sub-account dashboards](https://ideas.gohighlevel.com/changelog/configure-and-filter-your-general-widgets-in-sub-account-dashboards).

**Checked:** 2026-11-13. A feature announced only in Labs/private beta is not automatically generally available.
