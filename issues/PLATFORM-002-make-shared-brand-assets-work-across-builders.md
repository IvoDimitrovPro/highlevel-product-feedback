# PLATFORM-002 — Brand assets: Reuse across builders

**Product:** Platform / Builders
**Type:** UX
**Status:** New
**Impact:** Medium
**Date reported:** 2026-05-06
**Source:** [Zoom feedback index](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/zoom-feedback-index-2026.md) — 2026-05-06 Product Town Hall

## Observed
Brand Boards, shared colors/fonts, and Media Storage are inconsistent across product areas.

## Why it matters
Shared brand assets only save time if they are actually reusable across every relevant builder.

## Expected
Make shared Brand Board assets, colors, fonts, and logos available consistently across all relevant builders instead of reconfiguring them per product.

## HighLevel response
Some individual customizers exist; universal integration is not verified.

## Official changelog verification — 2026-11-13

**Result:** Partial implementation — request remains open.

**Already available:** Template preview can use a Brand Board's selected color palette.

**Scope decision:** Consistent Brand Board colors/fonts/logos/media across all builders is not demonstrated.

**Official sources:** [Templates in your Brand Colors](https://ideas.gohighlevel.com/changelog/templates-in-your-brand-colors).

**Checked:** 2026-11-13. A feature announced only in Labs/private beta is not automatically generally available.
