# MR-101 — Create and select meetings inline from other product areas

**Product:** Platform
**Type:** Feature
**Status:** Planned
**Date reported:** 2026-09-25
**Source:** [Meeting Room beta response](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/highlevel-meeting-room-response-2026-09-25.md)
**Impact:** High

## Observed
From Calendars, Courses, Events, or Funnels, users should select/create/edit a meeting without leaving the current flow, with a link to the full manager.

## Why it matters
Inline management removes context switching and duplicated configuration across HighLevel products.

## Expected
From Calendars, Courses, Communities, Events, and Webinar/Funnel setup, allow Select existing / Create / Edit inline plus a link to open the full Meeting Room manager.

## HighLevel response
Inline Meeting Room integrations are the direction; the team targeted this flow for the following week.

## Live webinar test follow-up — 2026-11-13

**Source:** [Sanitized test notes](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/meeting-room-webinar-test-2026-11-13.md)

The 2026-11-13 Sites > Webinars > Live Webinar wizard still asks for a pasted URL at step 3; it does not offer a native Meeting Room selector, creator, or a link to the room manager, although Meeting Room > Integrations documents the manual workflow. HighLevel's [webinar wizard guide](https://help.gohighlevel.com/support/solutions/articles/155000006062) also describes a manual URL field. Keep the earlier Planned status based on HighLevel's 2026-09 reply, but do not mistake that commitment for delivery.
