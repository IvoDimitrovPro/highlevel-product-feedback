# MR-201 — Workshops: Breakout rooms

**Product:** Meeting Room
**Type:** Feature
**Status:** Shipped
**Date reported:** 2026-09-25
**Source:** [Meeting Room beta response](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/highlevel-meeting-room-response-2026-09-25.md)
**Impact:** Medium


## Observed
Not required for initial rollout.

## Why it matters
Useful for workshops, classes and team sessions.

## Expected
Breakout rooms with host assignment/return and basic timing/control.

## HighLevel response
HighLevel originally considered breakout rooms; the official October 2026 changelog now confirms their release, with host assignment, timers, broadcast and return. [Release](https://ideas.gohighlevel.com/changelog/introducing-breakout-rooms-in-meeting-room).

## Official changelog verification — 2026-11-13

**Result:** Shipped.

**Already available:** Breakout Rooms are officially live: up to 100 rooms, manual/automatic assignments, host moves/broadcasts, timers, participant returns, and per-room recording/transcription.

**Scope decision:** The requested host assignment, return and basic session timing are all covered.

**Official sources:** [Introducing Breakout Rooms in Meeting Room](https://ideas.gohighlevel.com/changelog/introducing-breakout-rooms-in-meeting-room).
