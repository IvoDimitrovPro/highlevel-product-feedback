# MR-103 — Calendars: Session per appointment

**Product:** Calendars
**Type:** Feature
**Status:** Planned
**Date reported:** 2026-09-25
**Source:** [Meeting Room beta response](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/highlevel-meeting-room-response-2026-09-25.md)
**Impact:** High

## Observed
Calendar appointments should create/select a native session and preserve the relationship to the appointment.

## Why it matters
Meeting activity is most useful when it stays tied to the booking and the people involved.

## Expected
A Calendar booking should create or link a specific native Meeting Room session and keep the appointment, contacts, access, and session outcomes connected.

## HighLevel response
Planned Calendar integration maps each appointment to its own Meeting Session.

## Official changelog verification — 2026-11-13

**Result:** Partial implementation — request remains open.

**Already available:** A separate Meeting Room URL is automatically generated per Calendar appointment.

**Scope decision:** Linking the exact appointment/contact to attendance, recordings, transcript and outcomes end-to-end is not established.

**Official sources:** [Introducing Meeting Room](https://ideas.gohighlevel.com/changelog/introducing-meeting-room).

**Checked:** 2026-11-13. A feature announced only in Labs/private beta is not automatically generally available.
