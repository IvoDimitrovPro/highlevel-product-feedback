# MR-226 — Remote control: Control shared screens

**Product:** Meeting Room
**Type:** Feature
**Status:** New
**Date reported:** 2026-11-21
**Source:** Ivo product feedback (2026-11-21); [related HighLevel Ideas Board request](https://ideas.gohighlevel.com/ask-ai/p/make-ghl-meetings-a-true-zoom-replacement-for-coaching-programs-and-communities); [earlier remote mouse-control request](https://ideas.gohighlevel.com/scheduling-calendar/p/native-video-conferencing)
**Impact:** High

## Observed
Meeting Room documents screen sharing and screen-share permissions, but remote mouse/keyboard control of a participant's shared screen is not documented.

## Why it matters
Remote control helps hosts and participants with live troubleshooting, onboarding, training, and guided software demonstrations without switching to a separate remote-access tool.

## Expected
Add remote control for shared screens in Meeting Rooms: participants can request or grant control, with the screen owner's explicit consent and an immediate way to revoke it. HighLevel can choose the implementation.

## HighLevel response
No response or delivery commitment for this specific request verified as of 2026-11-21.

- [Zoom Replacement – Quick Meetings With No Login](https://ideas.gohighlevel.com/scheduling-calendar/p/native-video-conferencing) contains a public comment requesting mouse control with a consent popup.
