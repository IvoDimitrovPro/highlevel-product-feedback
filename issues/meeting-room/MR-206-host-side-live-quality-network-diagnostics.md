# MR-206 — Diagnostics: Live quality metrics

**Product:** Meeting Room
**Type:** UX
**Status:** Acknowledged
**Date reported:** 2026-09-25
**Source:** [Meeting Room beta response](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/highlevel-meeting-room-response-2026-09-25.md)
**Impact:** Medium


## Observed
PreJoin device checks already exist. The remaining gap is troubleshooting during the session.

## Why it matters
Hosts running larger sessions need to identify participant/network problems while live.

## Expected
Simple host quality dashboard for connection/audio/video problems and actionable diagnostics.

## HighLevel response
PreJoin checks devices. A broader host-side quality/network diagnostics dashboard is acknowledged useful feedback.

## Reliability focus — 2026-11-13

Praveen says engineering is prioritizing audio jitter, video freezing/choppiness and overall stability (MR-221). This is **not** a commitment to the host-side live quality/network diagnostics requested here. Keep Acknowledged.
