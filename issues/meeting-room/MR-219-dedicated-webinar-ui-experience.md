# MR-219 — Webinars: Dedicated attendee experience

**Product:** Meeting Room
**Type:** Feature
**Status:** Planned
**Date reported:** 2026-11-13
**Source:** [Praveen Gupta's GoKollab response](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/highlevel-meeting-room-webinar-response-2026-11-13.md)
**Impact:** High

## Observed
The current Meeting Room experience is meeting-oriented, while a webinar requires a clearer separation between presenter controls and an attendee-focused viewing experience.

## Why it matters
A webinar should be easy to present and watch without constant host intervention, gallery clutter, or friction on entry.

## Expected
Provide a dedicated webinar UI and attendee experience, with improved webinar host controls. Specific details should be scoped separately and only marked Planned when explicitly confirmed.

## HighLevel response
Praveen Gupta (Team kollab), 2026-11-13: HighLevel is **already planning a dedicated webinar UI and experience**, including improved host controls and a smoother attendee experience. No delivery date or item-level feature scope was provided.
