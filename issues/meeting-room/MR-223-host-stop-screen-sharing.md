# MR-223 — Screen share: Let hosts stop participant sharing

**Product:** Meeting Room
**Type:** Feature
**Status:** Planned
**Date reported:** 2026-11-13
**Source:** [Team kollab roadmap discussion, 2026-11-13](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/meeting-room-roadmap-community-discussion-2026-11-13.md)
**Impact:** Medium

## Observed
Marcel reports only the presenter can stop screen sharing and asks whether a host will be able to stop it from their controls. The original thread wording is ambiguous and should be confirmed against the exact control behavior.

## Why it matters
A host should be able to end inappropriate, accidental or stuck sharing without interrupting the webinar.

## Expected
Provide an explicit host/co-host action to stop another participant's screen share, with clear permissions and non-destructive UI. Confirm exact intended scope with HighLevel; do not reinterpret it as forcing a presenter to lose permission.

## HighLevel response
Praveen on 2026-11-13: **will plan the stop-sharing feature for next week** (week of Nov 16–22). This is a target for planning, not confirmation of shipping.
