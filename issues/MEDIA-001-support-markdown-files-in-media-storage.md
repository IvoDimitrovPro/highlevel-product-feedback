# MEDIA-001 — Media Storage: Accept Markdown files

**Product:** Media Storage
**Type:** File support
**Status:** New
**Impact:** Medium
**Date reported:** 2026-08-20
**Source:** [Zoom feedback index](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/zoom-feedback-index-2026.md) — 2026-08-20 Product Town Hall

## Observed
Ivo asked why .md files were unsupported and useful as light AI context.

## Why it matters
Markdown is a common lightweight AI/knowledge format; rejecting it adds conversion and upload friction.

## Expected
Allow Markdown files to be uploaded, stored, and selected anywhere text files are supported, including AI/knowledge workflows.

## HighLevel response
No platform response recorded.

## Town Hall follow-up — November 19, 2026

Ivo's **August 20** Product Town Hall question asked for Media Storage to accept Markdown `.md`; Jeff Valin replied he had raised it with Shivangi. The official [Media Storage format guide](https://help.gohighlevel.com/support/solutions/articles/48001216629-media-library-specs-formats) lists other text/code formats but does not explicitly list `.md`. [Ask AI Project](https://help.gohighlevel.com/a/solutions/articles/155000009329) and Managed Agent file support are separate surfaces and do not prove upload through the Media Library/pickers.

**Ask today:** Has `.md` been enabled in Media Storage itself? Is it accepted, previewed, selectable and processed by Ask AI/Courses through the same asset reference? Do not claim the feature is unavailable without a fresh authenticated upload test.
