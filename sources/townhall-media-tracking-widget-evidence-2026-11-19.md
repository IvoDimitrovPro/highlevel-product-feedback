To show events tracking in the Stats tab (of funnels and websites) along with the stats tab revamp. Direct wording: “give us the engine, not predefined stats that not all of us will want and need.” Also: “API to all analytics is essential.” Follow-up: prebuilt dashboards for nontechnical clients, with customizable widgets, filters, conditional logic, and the ability to connect data in external AI tools. ## Officially shipped / documented capabilities (do not ask for them as if absent)

- **Media Storage:** Public [file/folder API](https://marketplace.gohighlevel.com/docs/ghl/medias/media-files-folders/index.html), existing upload/list/update/trash, multi-select, folder upload, direct downloads, Media Picker in builders, workflow attachment selection. [Supported format guide](https://help.gohighlevel.com/support/solutions/articles/48001216629-media-library-specs-formats) lists TXT, JSON, CSS, but not specifically MD. **Ask AI/Managed Agents separately support Markdown**, which does not prove Media Storage accepts `.md` with every picker.
- **External Tracking:** Script, tracked external form/page analytics, contact attribution, domain/form control and [cross-domain iframe mapping in Labs](https://help.gohighlevel.com/support/solutions/articles/155000009476-field-mapping-and-iframe-form-tracking-in-external-tracking), named [workflow trigger](https://help.gohighlevel.com/support/solutions/articles/155000002292-a-list-of-workflow-triggers). Public feedback continues to request raw [GET data access and dashboard widgets](https://ideas.gohighlevel.com/external-tracking).
- **Chat Widget:** Public [management APIs](https://marketplace.gohighlevel.com/docs/ghl/chat-widget/chat-widget/index.html), [Live/Email widget creation release](https://ideas.gohighlevel.com/changelog/chat-widget-public-apis), [Snapshots](https://ideas.gohighlevel.com/changelog/chat-widget-snapshot-support), [inline all-widget-type embedding](https://ideas.gohighlevel.com/changelog/chat-widget-embed-any-chat-widget-inline), native [AI Studio widget insertion](https://ideas.gohighlevel.com/changelog/ai-studio-chat-widgets-native-live-chat-built-into-your-ai-studio-apps), spam controls, consent controls and attachments.
- **2026-11-16 Managed Agent video analysis:** [release](https://ideas.gohighlevel.com/changelog) covers video/Media Library source comprehension and transcripts/highlights. It is not confirmation of editable video caption assets propagated to Course lessons or independently accessible via Media Storage/API.
